# Agent Mission Control

Unified live dashboard that lets you **cycle through 5 agent visualization styles**:

1. **Graph Path** (LangGraphics-style)
2. **Pipeline Canvas** (AgentMesh-style)
3. **Animated DAG** (AgentForge-style)
4. **Crew Glow** (Crew AI Studio-style)
5. **Swarm Timeline** (Agent Swarm Dashboard-style)

## Live Demo

Open the single-file app:

**https://kmkirk83.github.io/agent-mission-control/**  
(or open `index.html` directly after enabling GitHub Pages)

Alternative instant preview (no setup):
https://raw.githack.com/kmkirk83/agent-mission-control/main/index.html

## Features

- Mode switcher to compare all 5 visual languages
- Live simulated agents representing your real workstreams:
  - Nail Growth (Instagram automation)
  - Kyzen Sales (P0 sale blockers)
  - Moneys Scout (zero-capital opportunity scan)
  - Portfolio Auditor
  - Swarm Orchestrator
- Progress bars, ETAs, reasoning snippets, handoffs
- Streaming timeline + collaboration view
- Pause / resume the simulation

## How to use

1. Open the live URL above
2. Click the mode buttons at the top to cycle through the five styles
3. Watch the agents progress and interact in real time

This is a self-contained static demo. Later you can wire the same UI to real LangGraph / CrewAI / swarm event streams.
